# 连接 WiFi 与网络异常排查

## 一、先分清是哪一类问题

三种现象的排查方向完全不同，先问清是哪一种：

| 现象 | 方向 |
|---|---|
| 搜不到网络名称 | 频段问题或路由器隐藏了 SSID |
| 能搜到但连不上 | 密码、加密方式或设备数上限 |
| 连上了但没网 | 路由器上游或 DNS 问题 |

把「连不上网」笼统当一个问题排查，会在错误的方向上反复试。

## 二、搜不到网络

### 2.1 频段

现在的路由器多数同时广播 2.4GHz 与 5GHz。iPhone、iPad、Mac 都支持双频，但部分配件类设备只支持 2.4GHz。

如果路由器把两个频段合并成同一个名称（常见叫法是「智能连接」「双频合一」），某些设备会一直连到不支持的那个频段上。**临时把两个频段拆成不同名称**，让设备明确连 2.4GHz 的那个，是最快的验证方法。

### 2.2 隐藏网络

路由器关闭了 SSID 广播时，列表里搜不到。在「设置－无线局域网－其他」里手动输入名称、加密方式与密码。

### 2.3 信道

路由器工作在 149 以上的高信道，或锁定了某些国家/地区不开放的信道时，设备可能搜不到 5GHz 网络。把信道设成自动通常就解决了。

## 三、能搜到但连不上

按这个顺序试，每一步之后再试连接：

1. **确认密码。** 区分大小写，注意中文输入法带进的全角字符
2. **忘记这个网络后重连。** 在「设置－无线局域网」点网络右侧的信息图标，选「忘记此网络」，再重新输入密码
3. **重启设备与路由器。** 路由器断电十秒再通电
4. **检查加密方式。** WPA3 在部分旧设备上会连不上，路由器改成 WPA2/WPA3 混合模式兼容性最好
5. **检查设备数上限。** 家用路由器通常有连接数限制，设备多时会把新设备拒在外面
6. **检查 MAC 地址过滤。** 路由器开了白名单时新设备连不上。iPhone 默认使用「专用无线局域网地址」，每个网络的 MAC 都不同，会让白名单失效——把这个开关关掉再加白名单

## 四、连上了但没网

WiFi 图标正常但打不开网页，问题通常不在设备上：

1. 用另一台已经正常的设备连同一个网络试。**都不行就是路由器或宽带的问题**，设备侧再怎么调都没用
2. 只有这一台不行，重置网络设置（「设置－通用－传输或还原 iPhone－还原－还原网络设置」）。这会清掉所有已存的 WiFi 密码，要重新输入
3. 检查有没有开启 VPN 或代理配置，关掉再试
4. 检查日期时间是否正确。时间偏差过大会导致证书校验失败，表现就是「连上了但所有网页都打不开」

## 五、HomePod 这类没有屏幕的设备

它们不自己输密码，而是从 iPhone 那里拿网络信息，所以有两条硬约束：

- **设置时 iPhone 必须已经连在目标网络上**，设置完成后 HomePod 连的就是那个网
- 要换网络必须用 iPhone 重新设置，设备本身没有入口

换了路由器之后 HomePod 掉线，就是因为它还在找旧网络：先让 iPhone 连上新网络，再用 iPhone 重新设置 HomePod。

## 六、换了路由器之后

新路由器的名称与密码和旧的完全一致时，多数设备会自动重连，什么都不用做。**这是换路由器最省事的办法**——提前把新路由器的 SSID 和密码设成和旧的一样。

名称或密码变了的话：

- iPhone、iPad、Mac 手动连一次新网络即可
- Apple Watch 跟随 iPhone，不需要单独设置
- HomePod 需要用 iPhone 重新设置
- 智能家居类配件需要在对应 App 里重新配网
