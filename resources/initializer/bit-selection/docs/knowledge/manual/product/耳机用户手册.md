# AirPods 用户手册（含按压与触控操作）

本手册适用于比特严选在售的 AirPods 5、AirPods Pro 3 与 AirPods Max 2。型号之间有差别的地方单独注明，具体以商品详情为准。

## 一、开箱与首次使用

1. AirPods Pro 3 与 AirPods 5 的包装内是左右耳机、充电盒、USB-C 充电线和资料，AirPods Pro 3 另附多种尺寸的硅胶耳塞。AirPods Max 2 是头戴式耳机，**没有充电盒**，附收纳保护套和 USB-C 充电线。
2. 检查耳机、充电盒触点和接口是否完好。耳塞、耳垫属于卫生附件，**用过后通常不支持七天无理由退货**，只想先看看的话不要戴。
3. 首次使用前先充电十分钟以上：AirPods Pro 3 与 AirPods 5 把耳机放进充电盒，AirPods Max 2 用 USB-C 线直接给耳机充。
4. 配对：AirPods Pro 3 与 AirPods 5 打开盒盖，AirPods Max 2 从保护套里取出，靠近已解锁的 iPhone，点弹出的「连接」。

## 二、基础操作

### 2.1 配对

**与 iPhone、iPad 配对：**

1. 设备解锁并打开蓝牙，停在主屏幕。
2. AirPods Pro 3 与 AirPods 5 留在充电盒里打开盒盖，把充电盒靠近设备；AirPods Max 2 从保护套里取出，靠近设备。
3. 屏幕上弹出连接动画后点「连接」，按提示完成设置。
4. 连接后，同一个 Apple 账户下的 iPhone、iPad、Mac 会自动识别这副耳机，不需要逐台重新配对。

**与安卓手机、Windows 电脑等非 Apple 设备配对：**

1. AirPods Pro 3 与 AirPods 5：耳机留在充电盒里，打开盒盖，连按两下充电盒正面，直到状态指示灯闪白光。
2. AirPods Max 2：按住右耳罩上的噪声控制按钮，直到状态指示灯闪白光。
3. 在设备的蓝牙列表里选择这副 AirPods。非 Apple 设备上用不了自动切换、空间音频个性化等功能。

### 2.2 佩戴与耳塞（AirPods Pro 3）

1. 先用中号耳塞，戴上后在「设置－[AirPods 名称]－耳塞贴合度测试」里测一次，系统会告诉你左右是否密封良好。
2. 密封不好就换大一号或小一号，左右耳可以用不同尺寸。
3. 耳塞贴合直接影响降噪和低频。耳塞属于耗材，变形、发黄、失去弹性就该换，一般半年到一年换一次。

AirPods 5 是半入耳设计，没有耳塞，戴时调整耳机柄的方向贴合耳廓。

### 2.3 按压与轻扫操作

AirPods 5 与 AirPods Pro 3 的耳机柄上有力度感应器，捏一下柄即可操作：

| 操作 | 默认功能 |
|---|---|
| 按一下 | 播放、暂停，接听来电 |
| 按两下 | 下一首 |
| 按三下 | 上一首 |
| 按住 | 在降噪、通透、自适应等模式间切换（支持降噪的型号） |
| 在柄上上下轻扫 | 调节音量（AirPods Pro 3，以及无线充电盒款 AirPods 5） |

按住的功能可以在「设置－[AirPods 名称]」里改成唤起 Siri，左右耳可以分别设置。

AirPods Max 2 用右耳罩上的数码表冠控制：转动调音量，按一下播放或暂停；旁边的噪声控制按钮切换降噪与通透。

### 2.4 充电与电量（AirPods Pro 3、AirPods 5）

1. 把耳机放回充电盒，确认吸附到位。
2. 用 USB-C 线给充电盒充电。MagSafe 充电盒与无线充电盒款也可以放在 MagSafe、Qi 认证充电器或 Apple Watch 充电器上充。
3. 打开盒盖靠近 iPhone，屏幕上会显示左右耳机和充电盒各自的电量；也可以在主屏幕添加「电池」小组件查看。
4. 指示灯：绿色表示电量充足，橙色表示电量不足或正在充电。
5. 耳机或充电盒潮湿时不要立即充电。

### 2.5 充电与电量（AirPods Max 2）

1. AirPods Max 2 没有充电盒，用 USB-C 线连接耳机上的 USB-C 接口直接充电。
2. 电量在 iPhone 主屏幕的「电池」小组件里看，或在「设置－蓝牙」里点耳机旁的信息按钮查看。
3. 不用时放进收纳保护套。
4. 充不进电时，先换一根线和一个插头再试，再检查 USB-C 接口有没有积灰。

## 三、进阶设置

### 3.1 降噪、通透与自适应

1. 打开控制中心，长按音量条，选择降噪、通透、自适应或关闭。也可以在「设置－[AirPods 名称]」里切换。
2. 地铁、飞机、办公室适合开降噪；过马路、骑行、跑步时用通透模式或调低音量。
3. 自适应音频会根据环境噪声自动调整降噪力度，嫌它变来变去就固定成降噪。
4. 降噪变差按这个顺序查：换一副新耳塞 → 做耳塞贴合度测试确认尺寸 → 清理出声口与通气孔 → 确认没切到通透模式。

### 3.2 在几台设备之间切换

同一个 Apple 账户下，耳机会自动切到正在播放声音的那台设备。不想被自动抢走的话，进入「设置－蓝牙」，点 AirPods 旁边的信息按钮，把「连接到此 iPhone」改成「上次连接到此 iPhone 时」。

### 3.3 左右音量与音频平衡

1. 「设置－辅助功能－音频与视觉」里有左右平衡滑块，要保持在正中间。
2. 这个滑块被误拖到一侧，会让一只耳机声音很小，听起来像坏了。

### 3.4 查找耳机

1. 打开「查找」App，选择这副 AirPods。
2. 可以看最后的位置，或让耳机播放提示音；AirPods Pro 3 的充电盒内置扬声器，盒子单独丢了也能响。
3. 播放提示音前先确认没有戴在耳朵上，提示音很响。

## 四、模式说明

| 模式名 | 适用场景 | 操作方式 |
|---|---|---|
| 主动降噪 | 通勤、飞机、办公室 | 按住耳机柄，或控制中心长按音量条 |
| 通透模式 | 户外行走、需要听环境音 | 同上 |
| 自适应音频 | 环境噪声经常变化 | 同上 |
| 对话感知 | 开口说话时自动调低音量 | 「设置－[AirPods 名称]」里开启 |
| 空间音频 | 看电影、听支持的音乐 | 控制中心长按音量条 |

## 五、保养与维护

- AirPods Pro 3 与 AirPods 5 的出声口、充电触点要定期清理：用干燥的软毛刷横向刷，**不要用尖锐物往里捅**，也不要用水或酒精直接冲。运动后先擦干汗水再放回充电盒。
- AirPods Max 2 的耳垫是磁吸安装的耗材，取下后用干布清洁，老化塌陷就换。
- AirPods 的抗汗抗水只防日常汗水和轻微泼溅，**不能戴着游泳或淋浴**；充电盒不防水。进液造成的损坏不在保修范围内。
- 长期不用时，每一两个月补一次电；AirPods Pro 3 与 AirPods 5 耳机和充电盒都要补。
- 送修时，AirPods Pro 3 与 AirPods 5 要把两只耳机和充电盒一起送，只送一只无法完整检测；AirPods Max 2 送耳机本身。

## 六、常见问题速查

| 问题 | 解决方法 |
|---|---|
| 只有一边有声音 | 一次做一步。AirPods Pro 3 与 AirPods 5：放回盒内合盖等 15 秒 → 清理无声那只的出声口 → 检查左右平衡 → 重置后重新配对，都做过仍无声，连同另一只和充电盒一起寄回检测。AirPods Max 2：检查左右平衡 → 重置后重新连接，仍无声寄回检测。可以转人工，能否免费保修或退换以检测结论为准 |
| 降噪效果差 | AirPods Pro 3 换一副耳塞、做耳塞贴合度测试；AirPods Max 2 看耳垫是否老化塌陷；都要确认没切到通透模式 |
| 充不进电 | AirPods Pro 3 与 AirPods 5 清理耳机柄底部和盒内触点，换线换插头再试；AirPods Max 2 换线换插头、清理 USB-C 接口；仍充不进需要寄回检测 |
| 在安卓手机上连不上 | AirPods Pro 3 与 AirPods 5 打开盒盖、连按两下充电盒正面；AirPods Max 2 按住噪声控制按钮；指示灯闪白光后再在蓝牙列表里选择 |
| 老是自动切到 iPad 或 Mac | 把「连接到此 iPhone」改成「上次连接到此 iPhone 时」 |
