# 日常保养与耗材更换

## 一、电池

### 1.1 什么时候该换

只看容量衰减的话，判据只有一个：**蓄电量低于原始容量的 80%**。

在 iPhone 的「设置－电池－电池健康与充电」里能看到最大容量百分比。iPad 与 Mac 没有这个界面，要由检测环节出报告。

- 保修期内低于 80%：属于保修范围，免费更换
- 保修期内高于 80% 但觉得掉电快：容量衰减属于正常损耗，要换只能付费，先排查是不是某个应用在后台耗电；如果伴随异常关机、无法充电、鼓包，这是故障，要寄回检测，不按容量判
- 过保：付费更换，参考价 iPhone 519-759 元、iPad 699-1099 元、MacBook 1099-1799 元、Apple Watch 599-899 元，以检测后报价为准

「感觉掉电快」不能作为判据。同一台设备在冬天室外与夏天室内的续航差异，可以大到让人误以为电池坏了。

### 1.2 怎么用能慢一点衰减

- 避免长期在高温下充电，尤其是边充边玩大型游戏
- 不必刻意把电用光再充，锂电池没有记忆效应
- 长期插电使用的设备（比如常年接电源的 Mac）开启「优化电池充电」，系统会把电量维持在 80% 左右
- 长期不用的设备存放时留 50% 左右电量，不要满电或空电存放

### 1.3 AirTag 的电池

AirTag 用的是 CR2032 纽扣电池，**用户可自行更换**，逆时针旋开背面不锈钢盖即可。电量低时「查找」App 里会提示。

这是唯一一个用户可自换电池的产品，其余都需要送修更换。

## 二、耳塞与耳垫

**AirPods 的硅胶耳塞**属于耗材，变形、发黄、失去弹性就该换。换耳塞不只是卫生问题——耳塞不贴合会直接影响降噪效果和低频表现，很多「降噪变差了」其实是耳塞老化。

清理方法：用清水冲洗耳塞（取下后再洗，不要连着耳机洗），彻底干燥后再装回。

**AirPods Max 的耳垫**同样是耗材，磁吸安装，直接拉下来更换。

耳机本体的出声口用干燥的软毛刷清理，**不要用尖锐物捅**，也不要用水或酒精直接冲。

## 三、表带

### 3.1 尺寸分档

表带按表壳尺寸分两档：**40/42 毫米一组、44/46/49 毫米一组**。跨档扣不上，这是买表带唯一必须先确认的事。

不知道自己表壳尺寸时，在手表的「设置－通用－关于本机」里看，或看订单。

### 3.2 清理

- **运动型与回环式运动表带**：可水洗，用清水冲洗后擦干
- **编织类**：用湿布擦拭，不要浸水
- **皮革类**：不要浸水，用干布擦；避免长期接触汗液
- **金属链式**：用湿布擦拭接缝处，注意擦干防止氧化

运动后及时擦干是延长寿命最有效的一件事，汗液长期残留会让织物发硬、皮革开裂。

### 3.3 什么时候算该换

开裂、脱胶、扣件松动就该换。褪色和轻微磨损属于正常损耗，不影响使用。

## 四、屏幕与机身

**屏幕**用柔软无绒布擦拭，可以稍微沾水。**不要用**：酒精含量高的清洁剂、漂白剂、含研磨颗粒的清洁产品、压缩空气。纳米纹理玻璃只能用随附的专用擦拭布，用别的布会损伤涂层。

**充电口**积灰会导致接触不良，表现是「充电时断时续」或「必须插很紧才充」。用木质或塑料牙签轻挑，不要用金属针——金属会刮伤触点，也可能短路。

**扬声器与麦克风开孔**用软毛刷横向刷，不要垂直往里捅。

## 五、防水的正确理解

标注 IP67 或 IP68 的产品**具备一定的防溅抗水能力，但这不是永久性的**。密封胶条会随使用老化，抗水能力会下降。

三条要记住：

1. **进液不在保修范围内**，不管防护等级标了多少
2. 不要主动带去游泳、洗澡、泡温泉——温度变化和水压都超出测试条件
3. 沾水后先擦干再充电。**湿着插线充电是最容易造成永久损坏的一种操作**

## 六、各品类保养要点速查

| 品类 | 重点 | 周期 |
|---|---|---|
| iPhone / iPad | 充电口清理、屏幕擦拭 | 按需，充电异常时先清口 |
| Mac | 散热口除尘、键盘缝隙清理 | 半年一次 |
| Apple Watch | 表带清洗、背面传感器擦拭 | 运动后即时 |
| AirPods | 耳塞清洗与更换、出声口清理 | 耳塞半年至一年换一次 |
| HomePod | 表面除尘 | 按需 |
| AirTag | 电池更换 | 一年以上，提示时换 |
