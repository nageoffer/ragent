# iPhone 操作进阶（截屏/录屏/快捷操作）

## 一、使用前先确认

本手册适用于比特严选在售的全部 iPhone 机型，前提是已经完成开机设置并登录 Apple 账户。

1. 「设置－通用－软件更新」里先装好可用更新，下文的入口以较新的 iOS 版本为准，旧版本的菜单位置可能不同。
2. 「设置－通用－关于本机」里确认机型名称。操作按钮、相机控制这类实体按键各机型配置不同：iPhone Duo 没有操作按钮，iPhone 17e 没有相机控制。
3. 想找某个开关却不知道在哪，直接在「设置」顶部的搜索框里搜功能名，比逐级翻菜单快。

## 二、基础操作

### 2.1 截屏

1. 同时按下侧边按钮和音量上键，然后立即松开。
2. 屏幕左下角出现缩略图后，点缩略图可以裁剪、标注或分享；向左轻扫缩略图则直接保存到「照片」。
3. **不要按住不放**：同时按住这两个键会进入关机滑块界面，不是截屏。

### 2.2 整页截屏

1. 在 Safari、备忘录、邮件等支持的应用里先完成普通截屏。
2. 点左下角缩略图，在编辑界面顶部选择「整页」。
3. 整页截图保存为 PDF，存到「文件」App，而不是「照片」。不支持的应用不会出现「整页」选项，可以分段截屏。

### 2.3 录屏

1. 先在「设置－控制中心」里把「屏幕录制」加进控制中心。
2. 从屏幕右上角向下轻扫打开控制中心，点屏幕录制按钮，三秒倒计时后开始。
3. 想同时录自己的声音，长按屏幕录制按钮打开麦克风。
4. 点屏幕顶部的红色状态条结束录制，视频保存在「照片」里。
5. 部分视频应用出于版权原因，录出来的画面是黑屏，这不是故障。

### 2.4 轻点背面

1. 进入「设置－辅助功能－触控－轻点背面」。
2. 分别给「轻点两下」「轻点三下」指定截屏、打开手电筒、静音等动作。
3. 戴了较厚的保护壳时识别率会下降，误触多的话关掉其中一项。

## 三、实体按键

### 3.1 操作按钮

除 iPhone Duo 外的在售 iPhone 都有操作按钮，位于机身左侧音量键上方，默认功能是切换静音模式。iPhone Duo 没有操作按钮，静音在控制中心里切换。

1. 进入「设置－操作按钮」，左右滑动选择功能：静音模式、专注模式、相机、手电筒、语音备忘录、识别音乐、翻译、放大器、快捷指令等。
2. 按住操作按钮执行选中的功能，轻按不会触发，避免误触。

### 3.2 相机控制

iPhone 16、iPhone 17、iPhone Air、iPhone 18 Pro、iPhone 18 Pro Max 与 iPhone Duo 在机身右侧下方有相机控制按钮，**iPhone 17e 没有**。

1. 按一下打开相机，再按一下拍照，按住录像。
2. 轻按两下调出曝光、景深、缩放、风格等选项，手指在按钮上左右滑动调节。
3. 「设置－相机－相机控制」里可以调整轻按力度，或改成锁屏时也能打开相机。

## 四、进阶设置

### 4.1 控制中心

1. 从屏幕右上角向下轻扫打开控制中心。
2. 点左上角的「+」或长按空白处进入编辑，可以添加、移除、拖动排序控制项，例如手电筒、屏幕录制、专注模式、低电量模式。
3. 长按某个控制项可以展开更多选项，例如长按音量条切换 AirPods 的降噪与通透模式。

### 4.2 多任务与画中画

**iPhone Duo 展开后支持分屏浏览，可以同时打开两个 App；其他在售 iPhone 没有分屏和小窗应用功能**，同时看两样东西靠的是画中画：

1. 播放视频或进行 FaceTime 通话时，从屏幕底部向上轻扫回到主屏幕，视频会缩成一个小窗口继续播放。
2. 拖动小窗口可以移动位置，双指捏合调整大小，拖到屏幕边缘可以暂时藏起只听声音。
3. 不是所有视频应用都支持画中画，以应用自身是否支持为准。

在应用之间切换：从屏幕底部向上轻扫并停顿，左右滑动选择应用；也可以沿屏幕底部边缘左右轻扫，直接切到上一个应用。

### 4.3 单手操作

1. 进入「设置－辅助功能－触控」，打开「便捷访问」。
2. 在屏幕底部边缘向下轻扫，屏幕上半部分会降下来，方便单手点到顶部内容。
3. iPhone 18 Pro Max 这类大屏机型单手够不到顶端时最常用。

### 4.4 手势速记

| 想做什么 | 怎么做 |
|---|---|
| 回到主屏幕 | 从屏幕底部向上轻扫 |
| 打开 App 切换器 | 从底部向上轻扫并停顿 |
| 返回上一页 | 在应用里从屏幕左边缘向右轻扫 |
| 打开通知中心 | 从屏幕左上角或顶部中间向下轻扫 |
| 打开控制中心 | 从屏幕右上角向下轻扫 |
| 搜索 | 在主屏幕中间向下轻扫 |

## 五、保养与维护

- 截屏、录屏和整页截图会占用存储空间，「设置－通用－iPhone 储存空间」里可以查看和清理。
- 保护壳过紧可能压住侧边按钮、音量键或相机控制，出现按键失灵、误触时先取下保护壳再试。
- 系统更新后入口位置变了，在「设置」顶部搜索功能名即可找到。
- 操作中卡死时强制重启：快按一下音量上键，快按一下音量下键，然后按住侧边按钮直到出现 Apple 标志。

## 六、常见问题速查

| 问题 | 解决方法 |
|---|---|
| 截屏变成了关机界面 | 两个键按住太久了，同时按下后要立即松开 |
| 整页截图找不到 | 整页截图存成 PDF，在「文件」App 里，不在「照片」里 |
| 录屏没有声音 | 录屏前长按屏幕录制按钮，打开麦克风 |
| 录屏画面是黑的 | 该应用禁止录屏，不是故障 |
| 想分屏同时开两个应用 | 只有 iPhone Duo 展开后支持分屏浏览；其他机型用画中画或 App 切换器 |
| 找不到相机控制按钮 | iPhone 17e 没有相机控制，按操作按钮或锁屏界面的相机图标打开相机 |
