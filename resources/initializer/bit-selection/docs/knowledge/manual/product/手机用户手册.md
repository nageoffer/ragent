# iPhone 用户手册（通用）

本手册适用于比特严选在售的全部 iPhone 机型。机型之间有差别的地方（SIM 卡、按键、充电功率）会单独注明，具体以对应商品详情的参数为准。

## 一、开箱与首次使用

1. 包装内是 iPhone、一根 USB-C 充电线（1 米）和纸质资料。**包装内不含电源适配器**，需要另配 USB-C 电源适配器。
2. 检查机身、屏幕、摄像头玻璃和 USB-C 接口是否完好，包装内物品先别丢，七天无理由退货需要包装、配件、资料完整。
3. 按住侧边按钮直到出现 Apple 标志，按屏幕提示设置语言、地区和网络。
4. 登录 Apple 账户，按需开启 iCloud、「查找」和 iCloud 云备份。

**联网走完设置流程，设备就已激活。** 激活或登录 Apple 账户后通常不再按七天无理由退货处理；只想先看看、保留无理由退货的余地，就只做外观检查，不要开机走设置流程。
5. 从旧手机迁移数据，最省事的是「快速开始」：新机停在「你好」界面时把旧 iPhone 靠近，旧机上弹出提示后扫描新机屏幕上的动态图案，选「从 iPhone 直接传输」。

## 二、基础操作

### 2.1 开机、关机与强制重启

- **开机**：按住侧边按钮，直到出现 Apple 标志。
- **关机**：同时按住侧边按钮和任一音量键，出现滑块后拖动关机；也可以在「设置－通用－关机」里操作。
- **强制重启**：快按一下音量上键，快按一下音量下键，然后按住侧边按钮直到出现 Apple 标志。按住要持续十秒以上，中途屏幕变黑也不要松手。

强制重启不会清除数据，只是让卡住的设备重新启动，未保存的编辑内容可能丢失。黑屏时按这个顺序排查：先接上充电器等 30 分钟，再强制重启，再换线、换插头；插上电仍完全没有反应，需要寄回检测确认原因，能否免费保修以检测结论为准。

### 2.2 SIM 卡与蜂窝网络

| 机型 | SIM 卡形式 | 怎么装 |
|---|---|---|
| iPhone 16、iPhone 17 | 双卡（两个 nano-SIM 卡） | 用取卡针打开侧面卡托放入 nano-SIM 卡 |
| iPhone 18 Pro、iPhone 18 Pro Max | 双卡：两个 nano-SIM 卡、一个 nano-SIM 卡加一个 eSIM，或两个 eSIM | 实体卡用取卡针装入卡托，eSIM 在「设置－蜂窝网络－添加 eSIM」里添加 |
| iPhone 17e | nano-SIM 卡 + eSIM | 实体卡同上，eSIM 在「设置－蜂窝网络－添加 eSIM」里添加 |
| iPhone Air、iPhone Duo | 双 eSIM，**不兼容实体 SIM 卡** | 只能在「设置－蜂窝网络－添加 eSIM」里添加，或到运营商营业厅办理 |

装好后在「设置－蜂窝网络」里确认号码已识别，按套餐打开 5G 与数据漫游。WiFi 在「设置－无线局域网」里连接。

### 2.3 面容 ID 与触控 ID

- 除 iPhone Duo 外的在售机型使用面容 ID：在「设置－面容 ID 与密码」里先设密码，再按提示录入面容。戴眼镜与不戴差别大时，可以添加替用外貌。
- iPhone Duo 使用触控 ID 指纹识别：在「设置－触控 ID 与密码」里录入。

识别率下降先清理屏幕顶部原深感镜头区域，检查保护壳和贴膜有没有挡住，再在「设置－面容 ID 与密码」里重设。

### 2.4 拍照和录像

1. 打开相机，左右滑动切换拍照、人像、夜间、视频、慢动作等模式。
2. 屏幕下方的 0.5x、1x、2x 等焦段按钮以机型实际镜头为准：iPhone 17e 与 iPhone Air 只有一颗后置主摄，没有 0.5x 超广角；iPhone 18 Pro 与 Pro Max 另有 4 倍与 8 倍长焦。
3. 有「相机控制」按钮的机型（iPhone 16、17、Air、18 Pro、18 Pro Max、Duo）按一下即可打开相机，轻按调曝光、景深与缩放；iPhone 17e 没有这个按钮。
4. 录制 4K 视频前检查剩余存储空间，长时间录像会发热，必要时降低分辨率。

### 2.5 充电与电量管理

1. 用 USB-C 线连接电源适配器或电脑充电。标称的快充速度需要足够功率的适配器，各机型要求不同，见商品详情「电源与电池」一项（例如 iPhone 17 的「20 分钟充至 50%」需 40 瓦或以上，iPhone 16 的「30 分钟充至 50%」需 20 瓦或以上）。电脑 USB 口功率低，充电会明显变慢。
2. 在售机型都支持 MagSafe 与 Qi2 无线充电，手机背面要与充电器中心对齐，保护壳过厚或夹着卡片时先取下。
3. **充到 80% 左右就不再涨，通常不是故障**，是下面两种设置之一，都在「设置－电池－充电」里：
   - **充电上限**：可在 80% 到 100% 之间按 5% 选。设在 100% 以下时，充到上限附近就停，插着电电量掉超过 5% 才会续充，偶尔充满一次用来校准电量显示。
   - **优化电池充电**：上限为 100% 时才生效。系统学习你的充电习惯，预测会长时间插着电时先暂缓在 80%，在你通常拔线前充满；急着用时在锁定屏幕上按住那条通知，点「立即充电」。
4. 机身过热时系统会暂停充电并提示，停止使用、取下保护壳，降温后会自动恢复。

## 三、进阶设置

### 3.1 系统更新

在「设置－通用－软件更新」里检查并安装。更新前先备份、连上 WiFi、保持电量 50% 以上或插电。刚更新完一两天耗电变快、发热比平时明显，是系统在后台重建索引，几天后恢复。

### 3.2 隐私与权限

1. 「设置－隐私与安全性」里按类别查看哪些应用能用定位、相机、麦克风、通讯录。
2. 单个应用的通知、后台刷新与蜂窝数据，在「设置－应用－对应应用」里调整。
3. Apple Pay、交通卡等 NFC 功能在「钱包」App 里添加，按提示验证。

### 3.3 显示与刷新率

1. 「设置－显示与亮度」里可切换浅色、深色外观，开启夜览（夜间屏幕偏暖）与原彩显示。
2. 支持 ProMotion 的机型（iPhone 17、Air、18 Pro、18 Pro Max、Duo）刷新率最高 120Hz，由系统自动调节，不需要手动开启；想省电可在「设置－辅助功能－动态效果」里打开「限制帧速率」。iPhone 16 与 17e 不支持 ProMotion。

### 3.4 备份与「查找」

1. 「设置－[你的姓名]－iCloud－iCloud 云备份」里打开自动备份，连接 WiFi 和电源、锁屏时会自动进行。
2. 「设置－[你的姓名]－查找」里打开「查找我的 iPhone」。开启后设备带激活锁，丢失后别人无法抹掉重新使用。
3. **退货、送修、出售前**要备份并抹掉数据、关闭「查找」、退出 Apple 账户，否则仓库或维修点无法验收。

## 四、模式说明

| 模式名 | 适用场景 | 操作方式 |
|---|---|---|
| 低电量模式 | 电量不足、外出无法及时充电 | 设置－电池－低电量模式，或控制中心 |
| 专注模式 | 会议、睡眠、工作时减少通知打扰 | 控制中心－专注模式，或设置－专注模式 |
| 静音模式 | 不想听到来电和提示音 | 按住操作按钮（默认功能，iPhone Duo 没有此按钮），或控制中心 |
| 夜览 | 夜间阅读、长时间看屏幕 | 设置－显示与亮度－夜览 |
| 深色模式 | 低亮环境 | 设置－显示与亮度－深色 |
| 飞行模式 | 乘机、排查信号问题 | 控制中心 |

## 五、保养与维护

- 机身和屏幕用柔软的无绒布清洁，不要把清洁液直接喷到听筒、扬声器和 USB-C 接口里。
- 在售 iPhone 达到 IP68 防溅抗水防尘，但**进液造成的损坏不在保修范围内**。接口进水时系统会提示检测到液体，这时拔掉充电线、停止充电，把手机接口朝下轻拍后自然晾干，不要用吹风机或往接口里塞纸巾。
- 电池适合在常温下使用，避免长时间放在暴晒的车内或低温户外。长期不用时把电量保持在 50% 左右关机存放。
- 保护壳、贴膜、充电器和线材选择对应机型和经过认证的产品，非认证线材可能出现「此配件可能不受支持」提示。

## 六、常见问题速查

| 问题 | 解决方法 |
|---|---|
| 新机刚用发热、耗电快 | 数据迁移、照片同步和应用恢复会带来高负载，完成后观察一两天 |
| 充到 80% 不再涨 | 充电上限设在 100% 以下会停在上限附近；上限为 100% 时的「优化电池充电」会暂缓在 80%、拔线前充满，急用时在锁定屏幕按住通知点「立即充电」 |
| 充电速度比宣传的慢 | 检查适配器功率是否达到该机型要求、线材是否认证、是否边充边用 |
| 黑屏、按键没反应 | 先接电等 30 分钟，再强制重启（快按音量上、快按音量下、按住侧边按钮），再换线换插头；插电仍完全没反应需要寄回检测 |
| 找不到实体卡托 | iPhone Air 与 iPhone Duo 只支持 eSIM，没有卡托 |
| 屏幕不自动旋转 | 控制中心里的竖排方向锁没关 |
