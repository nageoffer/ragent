# 系统更新与版本管理

## 一、更新前必做

**先备份。** 更新过程中断的概率很低，但一旦出问题，有备份才有退路。iPhone 与 iPad 用 iCloud 或电脑备份，Mac 用时间机器。

**留足空间与电量。** 空间不足是更新失败最常见的原因，系统会提示需要多少。电量建议 50% 以上，或者直接插电。

**用 WiFi。** 大版本更新包体积可观，蜂窝网络下系统通常会拦住不让下。

## 二、各设备的更新入口

| 设备 | 路径 |
|---|---|
| iPhone / iPad | 设置－通用－软件更新 |
| Mac | 系统设置－通用－软件更新 |
| Apple Watch | iPhone 的 Watch App－通用－软件更新 |
| AirPods | 无手动入口：AirPods Pro 3 与 AirPods 5 放进充电盒、盒子接电源，AirPods Max 2 接上电源充电，附近有已配对且联网的 iPhone 或 iPad 时自动更新 |
| HomePod | 家庭 App 内的设备设置里 |

## 三、Apple Watch 的更新有额外条件

手表更新比其他设备条件多，任何一条不满足都不会开始：

- iPhone 与手表都连在同一个 WiFi 下
- 手表电量 50% 以上
- 手表放在充电器上
- 两台设备保持靠近

更新过程可能持续较长时间，期间手表不可用，这是正常的。**中途不要把手表拿离充电器。**

## 四、AirPods 的固件更新是自动的

没有手动触发的入口。条件是：AirPods Pro 3 与 AirPods 5 放进充电盒、盒子接电源（AirPods Max 2 没有充电盒，耳机本身接上电源充电），附近有已配对且联网的 iPhone 或 iPad。满足后系统会在后台自己更新。

想确认当前版本：iPhone 的「设置－蓝牙」，点 AirPods 右侧信息图标，往下看固件版本。

**不能指定版本，也不能回退。**

## 五、更新失败怎么办

按这个顺序试：

1. **看空间**。不足就先清理再试，系统提示的所需空间通常比实际还要多留一些
2. **删掉已下载的更新包重下**。在「设置－通用－iPhone 储存空间」里找到系统更新项删除，回到软件更新重新下载。**下载不完整是「无法验证更新」这类报错最常见的原因**
3. **换网络**。公司网络或有代理的网络可能拦住更新服务器
4. **检查日期时间**。偏差过大会导致证书校验失败
5. **重启后再试**
6. **改用电脑更新**。连电脑后在访达里选「更新」——注意选更新不是恢复，恢复会抹掉数据

## 六、关于降级

**iPhone、iPad、Apple Watch 与 AirPods 没有降级途径。** 系统版本只能往前，装上新版本之后没有官方方法回到旧版本。

**Mac 不一样**：兼容的 Mac 可以安装以前版本的 macOS，但不能低于这台 Mac 出厂时的系统版本，一般要先完整备份、抹掉磁盘后重装，不能保证直接回退。

这一条要在更新前就想清楚：
- 有依赖特定版本的工作应用，先确认它支持新版本再更新
- 不确定的话晚一两周再更新，等其他人踩过坑

如果更新后遇到严重问题，可行的做法是等下一个修复版本，或联系官方支持。**任何声称能降级的第三方工具都不要用**，它们要么无效，要么会让设备变砖并失去保修。

## 七、更新后常见现象

这些是正常的，不是故障：

| 现象 | 说明 |
|---|---|
| 头一两天耗电明显变快 | 系统在后台重建索引、重新分析照片，几天后恢复 |
| 发热比平时明显 | 同上，后台任务集中 |
| 部分应用需要重新登录 | 钥匙串迁移导致，重新登录即可 |
| 存储空间比更新前少了 | 新系统本身占用更大，另有旧系统缓存待清理 |
| 某些设置被重置 | 大版本更新可能重置部分偏好设置，重新设置即可 |

超过一周仍持续发热耗电，再走故障排查。

## 八、要不要每次都更新

**安全更新建议装。** 它们通常体积小、只修安全问题，不改功能。

**大版本更新可以观察一段。** 尤其是工作设备，等到第一个小版本修复发布之后再更新，风险更低。

**旧设备要谨慎。** 机型较老时，新系统可能让日常操作变慢。更新前先看这台设备是否在新系统的支持列表里，以及同机型用户的反馈。
