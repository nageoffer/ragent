# Apple 账户与 iCloud 基础

## 一、一个账户管什么

Apple 账户是所有设备与服务的唯一身份。它同时管着四件事，出问题时先判断是哪一件：

| 范围 | 内容 |
|---|---|
| 登录与识别 | 设备激活、App Store 购买、iMessage 与 FaceTime |
| iCloud 数据 | 照片、通讯录、日历、备忘录、iCloud 云盘、设备备份 |
| 查找与激活锁 | 设备定位、丢失模式、抹除后仍绑定的激活锁 |
| 付费与订阅 | iCloud 空间、App 订阅、Apple 服务 |

## 二、iCloud 空间不够的处理顺序

免费空间有限，先看是谁占的：「设置－Apple 账户－iCloud－管理账户存储空间」。

占用大户通常是这三项，按影响从小到大处理：

1. **旧设备的备份**——已经不用的设备备份可以直接删，删掉不影响现有设备
2. **照片**——开启「优化 iPhone 储存空间」后原图在云端、本地留压缩版，能省下本地空间但不省云端空间。云端要省只能删或改用其他备份方式
3. **iCloud 云盘里的大文件**——在「文件」应用里按大小排序清理

真的不够就买更大的空间套餐，或改用电脑备份——电脑备份不占 iCloud 空间。

## 三、换设备时账户怎么处理

**新设备**登录账户即可，数据用快速开始（两台设备面对面直传）、iCloud 云备份或电脑备份三种方式之一恢复。

**旧设备**要按顺序做完：退出账户 → 抹掉所有内容和设置 → 在「查找」里移除这台设备。

**顺序反了会卡住。** 先抹除再想退出账户是做不到的，抹除后设备回到激活界面，激活时仍要求原账户密码——这就是激活锁。

## 四、激活锁

这是最常遇到的硬卡点，单独说清楚。

**它是什么**：设备与 Apple 账户的绑定关系。开启「查找」后，抹除设备并不会解除绑定，重新激活时仍要求原账户凭据。

**它挡住什么**：
- 二手设备无法激活使用
- 无法进入官方维修流程
- 无法折抵换新

**怎么解**：只有原账户能解。在原账户登录的 iCloud 网页版「查找」里，把这台设备从设备列表移除；或在设备上输入原账户密码激活。

**本店不能代解**，任何渠道声称能解激活锁的都要警惕——绕过激活锁的设备后续会有更多问题。

## 五、双重认证

账户默认启用双重认证：在新设备登录时，需要已信任设备上弹出的六位验证码。

- 验证码只出现在已经登录该账户的设备上
- 手上没有其他设备时，可以用「受信任电话号码」接收短信验证码
- **两样都没有就只能走账户恢复流程**，这个过程可能需要数天。所以建议至少保留一个受信任电话号码，并记住它

## 六、常见问题

| 现象 | 原因与做法 |
|---|---|
| 提示账户已被锁定 | 多次输错密码触发的保护。按提示走账户恢复，或在 iforgot 页面重置 |
| 收不到验证码 | 检查受信任设备是否联网、受信任号码是否还在用。可在已登录设备上主动获取验证码 |
| 照片没同步 | 检查两台是否同账户、是否都开启了 iCloud 照片、是否在充足电量与 WiFi 下 |
| 提示「此 iPhone 已与 Apple 账户关联」 | 激活锁，只有原账户能解：在 iCloud 网页版「查找」里移除这台设备，或在设备上输入原账户密码；本店不能代解 |
| 备份一直失败 | 多数是空间不足或网络中断。先看存储空间，再换网络重试 |
| 多个账户混用 | App Store 一个账户、iCloud 另一个账户是允许的但容易混乱，建议统一 |

## 七、与本店服务的关系

本店的订单、售后、优惠券不走 Apple 账户，用的是比特严选的账号，两者互不影响。

需要本店协助处理的是：设备保修状态查询、送修前的检查清单确认、折抵评估。**涉及 Apple 账户密码与验证码的事本店一律不经手**，也不会通过任何渠道向你索要。
