# Mac 常见故障排查

## 排查总原则

一次只让用户做一步。先问清机型（左上角 Apple 菜单－「关于本机」）、系统版本，以及问题是一直如此还是某次更新/某次操作之后开始。

Mac 的排查有一个其他设备没有的有力手段：**安全模式**。它只加载必要组件，能快速区分「系统本身的问题」和「某个第三方软件或登录项的问题」。

## 一、无法开机

### 第一步：确认供电

- 换一根线、换一个插头、换一个插座
- MacBook 看充电指示：接上后键盘是否有背光、是否听到风扇声
- 台式机看电源指示灯

### 第二步：长按电源键强制关机后再开

按住电源键十秒强制断电，松手，再按一次开机。

### 第三步：看有没有反应的迹象

| 现象 | 方向 |
|---|---|
| 完全无声无光 | 供电或主板问题，送修 |
| 有风扇声但屏幕黑 | 屏幕或显示链路问题 |
| 出现 Apple 标志后卡住 | 系统启动问题，试安全模式 |
| 出现问号文件夹 | 找不到启动磁盘，进恢复模式用磁盘工具检查 |
| 出现禁止符号 | 系统版本与硬件不兼容 |

## 二、出现问号文件盘

意思是找不到可启动的系统。

1. 关机后进入恢复模式（Apple 芯片机型：关机后长按电源键直到出现启动选项；Intel 机型：开机时按住 Command+R）
2. 打开「磁盘工具」，看内置磁盘是否还在列表里
3. **磁盘在**：对它执行「急救」，修复后重启
4. **磁盘不在**：硬件问题，送修

进恢复模式之前先确认有备份——修复磁盘有数据丢失风险。

## 三、安全模式怎么用

**Apple 芯片机型**：关机，长按电源键直到出现启动选项，选中启动磁盘，按住 Shift 点「在安全模式下继续」。

**Intel 机型**：开机后立刻按住 Shift，直到出现登录窗口。

在安全模式下试一遍原来出问题的操作：

- **安全模式下正常** → 问题来自第三方软件或登录项。在「系统设置－通用－登录项」里逐个关掉再正常启动排查
- **安全模式下仍然异常** → 系统或硬件问题，继续往下

## 四、卡顿与发热

### 4.1 先看是谁在占资源

打开「活动监视器」（应用程序－实用工具），按 CPU 和内存排序。

**常见的意外大户**：浏览器的某个标签页、云盘同步、刚更新完系统时的后台索引（进程名 `mds` 或 `mdworker`）。索引是暂时的，几小时到一天会结束。

### 4.2 存储空间

可用空间低于总容量 10% 时系统会明显变慢——虚拟内存没有腾挪空间。在「系统设置－通用－储存空间」里清理。

### 4.3 散热

MacBook Air 无风扇，长时间高负载会降频，这是设计如此不是故障。有风扇的机型如果风扇一直全速且机身很烫，检查散热口是否积灰。

## 五、外设与接口

| 现象 | 排查 |
|---|---|
| 外接显示器不亮 | 换线、换口；确认这台 Mac 支持的外接显示器数量与分辨率 |
| 移动硬盘不识别 | 换口、换线；在「磁盘工具」里看是否出现但未挂载 |
| 集线器上的设备时断时续 | 集线器供电不足，改用带独立供电的 |
| 雷雳设备速率异常低 | 用的是普通 USB-C 线。外观一样但速率差很多，要用雷雳线 |
| 键盘鼠标连不上 | 蓝牙问题，先关开一次蓝牙；有线设备换口试 |

## 六、系统与账户

### 6.1 忘记开机密码

在恢复模式里可以重置：进入恢复模式后选择「实用工具－终端」，或在登录界面多次输错后按提示用 Apple 账户重置（需事先启用该选项）。

### 6.2 应用打不开或提示来自身份不明的开发者

在「系统设置－隐私与安全性」里，被拦下的应用会出现「仍要打开」的按钮。**非官方渠道下载的应用不建议绕过这个检查。**

### 6.3 更新后某个应用不能用

多数是应用还没适配新系统。先看开发者有没有发更新，没有的话通常只能等。Mac 可以在兼容的机型上安装以前版本的 macOS，但能装回哪个版本取决于机型（不能低于出厂时的系统版本），而且一般要先完整备份、抹掉磁盘后重装，不能保证直接回退，操作前先核对兼容性。

## 七、电池（MacBook）

在「系统设置－电池－电池健康」里看状态。系统会给出「正常」或「建议维修」的结论。

- 显示建议维修且在保修期内：属于保修范围
- 电池鼓包（触控板顶起、机身合不上）：**立即停止使用并送修**，不要继续充电

## 八、什么时候直接送修

- 摔过、进液之后出现问题
- 屏幕有亮线、暗斑、大面积异常
- 完全不通电且换线换插头无效
- 磁盘工具里看不到内置磁盘
- 电池鼓包或机身变形
- 键盘多个按键失灵（Mac 的键盘多数机型要连同上盖整体更换，不要自己拆）
