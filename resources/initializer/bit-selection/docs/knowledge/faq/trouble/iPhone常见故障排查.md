# iPhone 常见故障排查

## 排查总原则

**一次只让用户做一步，等到结果再决定下一步。** 一口气抛五条建议，用户做完一堆也不知道该回什么，多轮诊断就塌成一轮。

先问清型号（「设置－通用－关于本机」里的型号名称）和现象发生的时机——是一直如此、某次更新后开始、还是摔过/沾水之后。**摔过或沾水的直接走保修判定，不在排查范围内。**

## 一、无法开机 / 黑屏

### 第一步：确认是不是没电

接上充电器等 30 分钟。电量彻底耗尽的设备插上电后要过一会儿才显示充电画面，不是插上就亮。

### 第二步：强制重启

- 快按一下音量上键，快按一下音量下键，然后按住侧边按钮直到出现 Apple 标志
- **按住不放要持续十秒以上**，很多人松手太早以为无效

### 第三步：换充电线和插头

用另一根线、另一个插头、另一个插座各试一次。线材内部断裂从外观看不出来。

### 第四步：看有没有充电反应

插上后屏幕完全没有任何反应（不亮、不震、电脑也不识别）：基础排查已经做完仍未解决，需要寄回检测确认原因，可以帮用户转人工；能不能免费保修、能不能退换，以检测结论为准。

## 二、充电异常

### 2.1 插上电完全不充（屏幕能亮）

屏幕能正常显示、只是插上电电量不涨、也没有充电图标，按这个顺序一次做一步：

1. **换线、换插头、换插座**：先换一根确定能用的 USB-C 线，再换一个电源适配器和插座各试一次。线材内部断裂从外观看不出来，这一步排除的情况最多。
2. **清理 USB-C 接口**：手电筒照一下接口，有絮状积灰就用木质或塑料牙签轻轻挑出来，不要用金属，也不要吹气（会带进湿气）。积灰会让插头插不到底。
3. **试一下无线充电**：放到 MagSafe 或 Qi2 充电器上。无线能充、有线不能，问题多半在接口或线材；两种都不能充，再往下走。
4. **看有没有温度或液体提示**：机身过热时系统会暂停充电，降温后自动恢复；提示检测到液体时先拔线晾干，干了再充。
5. **强制重启后再插一次**：快按一下音量上键，快按一下音量下键，然后按住侧边按钮直到出现 Apple 标志，按住要持续十秒以上。
6. 以上都做完仍然完全不充：基础排查已经做完仍未解决，需要寄回检测确认原因，可以帮用户转人工；能不能免费保修、能不能退换，以检测结论为准。

如果屏幕已经不亮、插电也没有任何反应，不按上面的顺序走，改按「无法开机 / 黑屏」排查：先接上充电器等 30 分钟，再强制重启，再换线换插头。

### 2.2 其他充电现象

| 现象 | 先查什么 |
|---|---|
| 时断时续 | 线材接口松动或接口积灰，按 2.1 第 1、2 步 |
| 充到 80% 左右不再涨 | 两种设置都会这样，不是故障：「设置－电池－充电」里充电上限设在 80%～95%，会停在上限附近，只偶尔充满一次用来校准；上限为 100% 时生效的「优化电池充电」，会按充电习惯暂缓充到 80% 以上，在你通常拔线前充满，急用时在锁定屏幕上按住通知点「立即充电」 |
| 充电很慢 | 适配器功率不够。各机型标称快充要求的功率不同（20 瓦到 60 瓦不等），见商品详情「电源与电池」；电脑 USB 口功率很低 |
| 充电时发烫 | 边充边玩会明显发热。取下保护壳、停止使用再观察 |
| 提示「此配件可能不受支持」 | 线材或配件非认证产品，或接口有异物 |
| 无线充电不工作 | 壳太厚、壳里有金属或卡片、对位不准。摘掉壳再试 |

## 三、面容 ID 识别不了

按顺序排查：

1. **清理原深感镜头区域**——屏幕顶部的开孔处有指纹或膜的残胶都会影响
2. **确认没有遮挡**——保护壳边缘、钢化膜开孔位置偏移都可能挡住
3. **看是不是特定场景失败**——强光直射、完全黑暗、戴口罩（未设置戴口罩解锁）都会降低成功率
4. **重设面容 ID**——「设置－面容 ID 与密码」里移除原有设置后重新录入
5. **添加替用外貌**——戴眼镜与不戴眼镜差异大时，这一项很有效

以上都试过仍频繁失败，且「设置－面容 ID 与密码」里出现无法启用的提示，多半是硬件故障，需要寄回检测确认。

## 四、屏幕问题

| 现象 | 判断 |
|---|---|
| 触控局部无响应 | 先强制重启。仍然如此，需要寄回检测确认原因 |
| 屏幕有绿线或彩条 | 硬件问题，直接送修 |
| 显示偏色 | 检查是否开启了原彩显示或夜览。在「设置－显示与亮度」里关掉再看 |
| 屏幕不自动旋转 | 控制中心里的竖排方向锁没关 |
| 屏幕自动变暗 | 自动亮度，或设备过热触发保护 |

**摔过之后出现的任何屏幕问题都不属于免费保修**，可能适用 AppleCare+ 的意外损坏保障。

## 五、信号与通话

### 5.1 没有信号

1. 开关一次飞行模式
2. 重启设备
3. 取出 SIM 卡重插（实体卡），或在「设置－蜂窝网络」里检查 eSIM 是否启用
4. 换一个地点试——判断是设备问题还是基站覆盖问题，这一步最有效
5. 重置网络设置（会清掉所有 WiFi 密码）

### 5.2 通话对方听不清

- 检查底部麦克风开孔有没有被壳挡住或积灰
- 换成免提或插耳机通话，判断是主麦克风还是整体问题
- 打开语音备忘录录一段自己听，能直接确认麦克风好不好

## 六、耗电异常

先看「设置－电池」里的用电排行，**多数「耗电快」都能在这里找到具体的应用**。

排除应用因素后再看电池健康度。在「设置－电池－电池健康与充电」里看最大容量：低于 80% 且在保修期内属于保修范围，可免费更换。高于 80% 只说明容量衰减还没到免费换电的标准，不代表电池或设备没有故障；有异常关机、无法充电、电量跳变这类现象的，仍要继续排查或寄回检测。

刚更新完系统的一两天耗电偏快是正常的，系统在后台重建索引、重新分析照片，几天后恢复；超过一周仍耗电快再继续排查。

## 七、发热

分清两种情况：

- **使用中发热**：游戏、导航、长时间视频通话、边充边玩，都会明显发热，属正常
- **待机发热**：放着不动也烫，通常是某个应用在后台持续活动。看电池用量排行，或重启观察

**持续高温会触发降频与充电暂停**，屏幕上会出现温度警告。此时停止使用、取下保护壳、放在阴凉处等待，不要用冰箱或风扇急速降温。

## 八、什么时候直接送修

以下情形不用继续排查，直接走保修判定：

- 摔过、进液、挤压之后出现问题
- 屏幕有绿线、彩条、大面积不显示
- 完全不通电且换线换插头无效
- 屏幕能亮但插电完全不充，换线换插头、清理接口、强制重启都做过仍无效
- 出现无法消除的硬件提示（如无法启用面容 ID）
- 机身变形、电池鼓包

**电池鼓包要立即停止使用并送修**，不要继续充电。
