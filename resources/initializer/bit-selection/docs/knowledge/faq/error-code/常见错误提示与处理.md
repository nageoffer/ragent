# 常见错误提示与处理

## 怎么用这份文档

Apple 设备的错误提示多数是**文字描述**而不是编号，所以按提示原文找。用户描述不清时让他截图或念出完整提示——「更新失败」和「无法验证更新」是两个不同的问题。

下表中「自助」表示用户能自己解决，「送修」表示需要走维修流程。

## 一、激活与账户

| 提示 | 含义 | 处理 | 归属 |
|---|---|---|---|
| 此 iPhone 已与 Apple 账户关联 | 激活锁。设备仍绑定在原账户上 | 只有原账户能解，在 iCloud 网页版「查找」里移除该设备 | 自助（需原账户） |
| 激活时出错 / 无法激活 iPhone | 激活服务器暂时不可达，或网络受限 | 换网络重试；连电脑用访达激活 | 自助 |
| 您的 Apple 账户已被锁定 | 多次输错密码触发保护 | 在账户恢复页面重置密码 | 自助 |
| 无法登录，验证码发送失败 | 受信任设备不在线或号码已停用 | 用受信任电话号码接收短信；都不行走账户恢复 | 自助 |
| 此 Apple 账户尚未在 App Store 使用过 | 账户未完成首次条款确认 | 在 App Store 登录一次并同意条款 | 自助 |

**激活锁本店不能代解**，也不会向你索要 Apple 账户密码或验证码。

## 二、系统更新

| 提示 | 含义 | 处理 |
|---|---|---|
| 无法验证更新 | 下载的更新包不完整 | 在「设置－通用－iPhone 储存空间」里删掉已下载的系统更新，连稳定 WiFi 重新下载 |
| 存储空间不足，无法安装 | 剩余空间不够解压安装 | 清理空间；或连电脑用访达更新，占用更少 |
| 更新请求超时 | 网络问题或服务器繁忙 | 换网络重试；避开刚发布的高峰时段 |
| 安装时发生错误 | 多种原因 | 重启后重试；仍失败则连电脑更新 |
| 此更新不再可用于您的设备 | 该版本已停止签名 | 只能更新到当前最新版本，无法装指定旧版本 |
| 准备更新… 卡住不动 | 正在校验，大版本可能耗时较久 | 保持联网插电等待；超过一小时无进展则重启重试 |

## 三、充电与配件

| 提示 | 含义 | 处理 |
|---|---|---|
| 此配件可能不受支持 | 线材或配件未通过认证，或接口有异物 | 清理充电口；换认证线材 |
| 此配件需要更多电源 | 外设功耗超过接口供电能力 | 改用带独立供电的集线器 |
| 检测到液体 / 充电口检测到液体 | 接口处有水分 | **停止充电**，擦干后自然干燥数小时再充 |
| 暂时无法充电，温度过高 | 触发高温保护 | 停止使用，取下保护壳，放阴凉处等降温 |
| 无法进行无线充电 | 对位不准，或壳太厚/含金属 | 摘壳重试 |

**「检测到液体」时强行充电是最容易造成永久损坏的操作。** 进液不在免费保修范围内。

## 四、网络与连接

| 提示 | 含义 | 处理 |
|---|---|---|
| 无法加入网络 | 密码错误、加密方式不兼容或被路由器拒绝 | 忘记此网络后重连；检查 WPA 加密模式 |
| 已连接，但无互联网连接 | 设备到路由器正常，路由器到外网有问题 | 用另一台设备验证；重启路由器 |
| 安全性较弱 | 路由器用了过时的加密方式 | 提示而非故障。可在路由器上改成 WPA2/WPA3 |
| 隐私警告 | 该网络不支持专用地址 | 提示而非故障 |
| 未安装 SIM 卡 | 卡未识别 | 重插卡；换卡验证；eSIM 检查是否启用 |

## 五、Mac 启动相关

| 现象 | 含义 | 处理 |
|---|---|---|
| 问号文件夹 | 找不到可启动系统 | 进恢复模式（Apple 芯片机型关机后长按电源键直到出现启动选项）用磁盘工具急救；磁盘不在列表里多半是硬件故障，需要送修检测 |
| 禁止符号（圆圈斜杠） | 系统版本与此硬件不兼容 | 进恢复模式重装适用的系统版本 |
| 空心电池图标 | 电量过低无法启动 | 接电源充一段时间再开 |
| 锁形图标要求固件密码 | 开启过固件密码 | 输入该密码；忘记只能送修由官方处理 |
| 屏幕变灰并提示重新启动 | 系统崩溃 | 偶发可忽略；频繁出现试安全模式排查第三方软件 |

## 六、iTunes / 访达 恢复错误码

连电脑恢复或更新时出现的数字错误码，常见这几类：

| 错误码 | 大致方向 | 处理 |
|---|---|---|
| 9 / 4005 / 4013 / 4014 | 传输中断，多为线材或接口问题 | 换原装线、换电脑接口、避开集线器 |
| 14 | 同上，数据传输错误 | 换线重试 |
| 3194 / 17 | 无法联系更新服务器 | 检查网络与代理设置 |
| 53 | 检测到部件识别异常 | 常见于经非授权维修更换过部件，需送修 |
| 4000 系列反复出现 | 硬件层面问题概率较高 | 送修 |

**错误码 53 值得单说**：它通常出现在经非授权渠道更换过指纹/面容组件之后。这也是不建议走非授权维修的具体理由之一。

## 七、Apple Watch

| 提示 | 处理 |
|---|---|
| 无法与 iPhone 通信 | 两台都重启；检查蓝牙与 WiFi；必要时解除配对重配 |
| 更新未能完成 | 确认电量 50% 以上、在充电器上、与 iPhone 同一 WiFi |
| 无法验证身份 | 手腕检测与密码设置问题，重新设置手表密码 |

## 八、什么提示直接意味着送修

- 错误码 53，或任何提到「无法验证部件」的提示
- 反复出现的 4000 系列恢复错误
- Mac 开机出现禁止符号且重装系统仍失败
- 提示电池需要维修
- 磁盘工具中看不到内置磁盘
